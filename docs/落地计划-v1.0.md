# Paw Pad v1.0.0 落地计划

> 本文档是将 MVP 验收后全部设计决议（D14-D36）落地为代码的交接物。
> MVP 已交付验收（14 任务卡 + 冒烟 11 项 + 三层验收），本文档覆盖 P1 功能迭代。
> 设计演进文档（D1-D36，唯一事实源）在 `docs/QwenPaw轻量助手—设计演进文档.md`。

---

## 全局约束

- 技术栈：Tauri v2（Rust 原生壳）+ React + TypeScript + Vite
- 架构：薄壳复用——连接 `localhost:8088` 的 QwenPaw 后端，不打包后端（D2/D13）
- 仅 macOS（D24/#24），最低 macOS 15（D17 vibrancy）
- 轻量化（D11）：不引重型组件库，动画少而精，无侧边栏/导航/设置面板
- 发送纪律（C5/D8）：无队列、无重放、无重试，显式发送
- 委派铁律：交付师只交付代码+秒级自证，贵验证（编译/构建/e2e）后置到验收阶段

## 落地顺序（建议）

```
模块 4（窗口行为）→ 模块 1（浮球系统）→ 模块 5（连接体系）
→ 模块 2（文件交互）→ 模块 3（截图）→ 模块 6（信息架构+快捷键+日志）
→ 模块 7（草稿+去重）
```

**理由**：窗口行为是其他一切的基础（尺寸/位置/状态）→ 浮球是核心入口 → 连接是使用前提 → 文件交互/截图是 P1 功能 → 信息架构收纳低频 → 草稿/去重是收尾。
