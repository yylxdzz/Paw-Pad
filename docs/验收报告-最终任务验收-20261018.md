## 六、QwenPaw 行为实证备查（过程知识存档）

1. **chat API 消息结构**：必须 `{input:[{content:[{type:"text",text}]}]}`，顶层 `content` 字段被忽略（api-tutorial.zh.md 的示例是简化版，文档坑）
2. **命令消息不落 chat history**：`/compact` 等命令执行后只 touch chat 的 updated_at，不作为 user/assistant 消息落录——验证命令是否执行应查 updated_at 或流式回执，不是历史列表
3. **`chats/{chat_id}` 只认 chat UUID**：session_id 当路径参数 404，需经 listChats 映射（history.ts 的 resolveChatId）
4. **macOS 26 材质 API 代差**：NSVisualEffectView 在 macOS 26 无 light rim，Liquid Glass（NSGlassEffectView）才有玻璃质感；window-vibrancy 0.8.1 已内置 apply_liquid_glass（内部版本检测 <2685 返 Err，调用侧 try/fallback）
5. **本机 Rust 编译**：沙箱强制 Mach-O 代码签名，RUSTC_WRAPPER 签名 wrapper 已固化于 `/Users/duzuzeng/.copaw/workspaces/jvLB6y/scripts/rustc-sign-wrapper.sh`；cargo 走 rsproxy 镜像
